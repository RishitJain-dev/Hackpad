# **Hackpad**
  A custom 6-key mechanical Macropad with rotary encoder, OLED screen and fully programmable shortcuts for your workflow.

  ## 1. Designing the macropad - 20 minutes
   I used Figma to create initial designs before designing the PCB and schematic

 ## 2. Designing the schematic - 30 minutes
 
 ### Components:  
   -ER_OLEDM0.91_1x-I2C  
   -RotaryEncoder_Switch_MP  
   -XIAO_ESP32C3  
   -Cherry MX Switches  
   -1N4001 Diode
